# PDD Overlay RU v0.2.0-beta.3 — runtime safety

## Added / Improved
- Bounded ML Kit translation tasks: maximum 24 active unique labels and four listeners per label.
- A translation that has not completed within 30 seconds cannot update the overlay later; only a fresh request with a new ticket may publish a result. A timed-out source has a 30-second retry cooldown.
- Translation labels are suppressed on exact-match, sensitive purchase/payment/confirmation/refund action buttons so the Chinese/English source action remains visible. Ordinary product details and payment-method information remain translatable.
- Regression tests for queue capacity, stale task completion, deduplication, retries and payment-button protection.
- Android `versionCode 13`, `versionName 0.2.0-beta.3`; unchanged application ID `app.pinduoduo.overlayru`.

## Compatibility and limitations
- Existing Pinduoduo is not modified. Translation remains free and independent of PRO. Accessibility permissions and ML Kit offline model consent remain unchanged.
- Financial totals are still subject to the existing translation policy, which does not cover displayed currency amounts; the new protection targets explicit confirmation actions.
- The protected action dictionary is intentionally conservative and not exhaustive for all Pinduoduo variants. Actual checkout flows must be inspected on a physical phone before a production claim.
- There is still no OCR for screenshots/product photographs, no in-app payment flow and no commercially meaningful PRO-only translation feature.
- The package can update an installed PDD Overlay RU beta2 **only when signed by exactly the same certificate**. The previous v0.2.0-beta.2 Kotlin build's new certificate SHA-256 is `d0d4e5dfb604917e1896c9a4697f2743296e3fa7b137d5bacefdf7a8c7b519d3`. Earlier v0.1.x APKs used another certificate and cannot be updated in place.
- CI artifacts are debug or unsigned until signed explicitly. APK installation, ML Kit model download and overlay behavior on a physical device still require validation.

## Verification contract
- `bash pinduoduo_overlay_ru/scripts/test_local.sh`
- `gradle -p pinduoduo_overlay_ru :app:testReleaseUnitTest :app:assembleDebug :app:assembleRelease`
- 30 existing plus 9 new JUnit tests (39 total) must pass in the beta3 GitHub workflow.
- The actual APK signing certificate must be verified after the final signing step; a successful unsigned CI build alone is not a release.
