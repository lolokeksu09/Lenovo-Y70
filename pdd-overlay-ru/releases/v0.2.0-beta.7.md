# PDD Overlay RU v0.2.0-beta.7 — OCR regions on images (ARM64)

## Added
- A **"Посмотреть текст на изображении"** button in the existing OCR screen, only when the chosen image actually contains recognized eligible text with known positions.
- Full-screen viewer of the selected photo. It highlights the recognized locations of eligible labels; tapping a highlighted region shows the original text and its current Russian translation in a readable panel.
- The position math uses ML Kit text-line rectangles normalized against the original bitmap, then maps them to the actual image fit area including letterboxing. No broad screenshot permissions or on-device screen capture.
- Increased the independent preview's maximum longest edge from 620 to 1600 pixels for legibility while preserving the existing bounded URI decoder.
- Preserved rectangles while async ML Kit translation finishes and updates the displayed lines.

## Unchanged
- The original Chinese bitmap is **never modified**. This is an interactive annotation viewer, not pixel replacement/retypesetting. Prices and checkout confirmation labels remain unmodified and are excluded from selectable highlights.
- Offline Chinese/English-to-Russian via the previously downloaded ML Kit models, local editable dictionary, existing Pinduoduo Accessibility overlay and licensing.
- No new photo/storage permissions, no extra network or telemetry collection, no key rotation.
- **Only ARM64 APK:** `ndk { abiFilters 'arm64-v8a' }`; app ID `app.pinduoduo.overlayru`, `versionCode 17`, `versionName 0.2.0-beta.7`.

## Checks and limitations
- 52 existing JVM tests plus 6 new `OcrRegionTest` scenarios (portrait screenshot fit, letterboxing, invalid bounds, hit detection).
- Android CI assembles ARM64 release; APK inspected for native OCR and translation libraries and exclusive `arm64-v8a`.
- The signed APK must use the **same new Kotlin signer** as beta6 (certificate SHA-256 `d0d4e5dfb604917e1896c9a4697f2743296e3fa7b137d5bacefdf7a8c7b519d3`).
- End-to-end OCR and photo tapping on Lenovo Legion Y70 require real-device validation. Not every background or complex graphical caption is expected to be detected; a photo with no recognized text has no highlights. Long screenshots are shown fit-to-screen, not digitally zoomed.
