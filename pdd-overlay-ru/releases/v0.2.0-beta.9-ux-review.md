# PDD Overlay RU — UX review and design decisions (beta9)

Date: 2026-11-16. Basis: current Kotlin Compose source in `pdd-overlay-ru-compose-single-v020`, not a rendered device screenshot. **Do not treat compile as proof of visual quality on a phone.**

## UX thesis

A serious Pinduoduo translation tool, not a pseudo-premium dashboard. **One primary task:** enable/launch translation; **two supporting tasks:** OCR a product image, correct specialized vocabulary. Admin, licensing and diagnostics must not interrupt setup or buying workflows.

### Problems found in beta8

| Priority | Actual source | Finding | Why users notice | Resolution in beta9 |
| --- | --- | --- | --- | --- |
| P1 | `ui/home/HomeScreen.kt` | Huge marketing hero, repeated settings paths and two-character fake tool icons | Primary translation task is pushed below fold, tool visuals are generic | Compact task-first Home, small brand bar, action-state panel, native drawn scanner/book icons |
| P1 | `MainActivity.kt` | License shown before models/permissions; duplicate large Pinduoduo open button | Monetization obstructs basic setup | Move licensing and duplicate open shortcut after service/models/controls |
| P1 | `GlossaryEditorActivity.kt` | Saved translations could only be deleted, not edited directly | Corrections require re-entering the Chinese source | Add `Править`, prefill edit form and scroll to it |
| P2 | `MainActivity.kt` | Still asserts OCR on images does not exist | User cannot trust product instructions | Correct the copy to manual image-picker OCR |
| P2 | Home/OCR/Glossary/Settings | Slightly different black, red, greys and shapes | Feels like separate unfinished screens | Shared Material3 dark palette for Compose and matching legacy colors |
| P2 | `ui/home/HomeScreen.kt` | Fixed-height and over-generous hero spacing | Poor density with larger system font | Flexible minimum touch heights, shorter content, max width 560 dp |

### Shared layout direction
- Canvas #080A0E, panel #151A21, elevated #212630, text #F6F7FA, secondary #B5BDC9, outline #343B46.
- Product red #EB4055 reserved for primary action, selected tool and essential emphasis; mint green means available/ready.
- Typography via Material 3 roles; minimum 48 dp interactive targets.
- No fake usage counts, fabricated PRO savings or neon glows.
- On a normal portrait phone, the status/action and both tools should appear without needless promotional copy. Verify on real device.

### Preservation contract
- Preserve `applicationId app.pinduoduo.overlayru`, ARM64-only distribution, all Accessibility permission semantics, explicit offline model consent, basic translation always free, existing PRO licensing, privacy rules and persistent user dictionary.
- v0.2.0-beta.9 / versionCode 19. Use the same new Kotlin release cert to update beta8 without removing settings.

### Validation
- Source migration/static UX contracts; `scripts/test_local.sh`.
- `:app:testReleaseUnitTest` all 66 regression cases; `:app:assembleRelease`.
- Verify ABI and signing certificate and distribute only the signed arm64-v8a APK.
- **Not tested:** actual screen screenshots, 1.3 font scale, TalkBack, rotation, press/retry and navigation on user's Lenovo Legion Y70. These remain acceptance gates.
