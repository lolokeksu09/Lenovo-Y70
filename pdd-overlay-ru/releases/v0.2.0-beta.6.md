# PDD Overlay RU v0.2.0-beta.6 — ARM64 only

## Для кого
Только устройства Android 8.0+ с 64-битной архитектурой ARM (`arm64-v8a`), в том числе Lenovo Legion Y70. APK **не поддерживает** x86, x86_64 и 32-битный ARM. Только один подписанный ARM64 APK должен передаваться пользователю.

## Изменения
- В Gradle defaultConfig включён `ndk { abiFilters 'arm64-v8a' }`. Сохраняются `libtranslate_jni.so` и `libmlkit_google_ocr_pipeline.so` именно для ARM64.
- Перестроен главный экран PDD Overlay RU: чистый AMOLED фон, приоритет статуса и запуска перевода, отдельные понятные разделы «Инструменты» и «Приложение».
- OCR товара и личный словарь доступны напрямую без поиска во вложенных настройках. Служба специальных возможностей, скачивание ML Kit модели и управление PRO сохраняются.
- Сохранены офлайн-перевод, ручной OCR выбранных изображений, локальный пользовательский словарь, ограничения для цен/кнопок оплаты и лицензирование.
- `applicationId app.pinduoduo.overlayru`, `versionCode 16`, `versionName 0.2.0-beta.6`.

## Верификация
- Android Gradle release сборка, проверки исходников и 52 JUnit теста.
- Проверка *реального файла APK*: все `lib/*.so` расположены исключительно в `lib/arm64-v8a/`, при этом в APK присутствуют обе библиотеки машинного перевода и OCR.
- Подпись: **только прежним новым Kotlin release-сертификатом**, SHA-256 `d0d4e5dfb604917e1896c9a4697f2743296e3fa7b137d5bacefdf7a8c7b519d3`; debug и unsigned APK не являются релизом.
- Новый сертификат Kotlin-серии несовместим с историческим v0.1.x сертификатом — тем старым версиям требуется миграция установки.

## Ограничения
- ARM64-фильтр уменьшает APK за счёт удаления чужих архитектур. Он не удаляет модели OCR/перевода и не меняет их функциональность.
- Изменение интерфейса подтверждается компиляцией и источниками. Реальные скриншоты и взаимодействие на Lenovo Legion Y70 должны быть проверены отдельно.
- Приложение не проводит оплату товаров и не гарантирует качество перевода условий доставки/покупки.
