# PDD Overlay RU v0.2.0-beta.4 — OCR and personal translation corrections

## Implemented
- **Image OCR (Chinese):** explicitly choose a screenshot or product image through Android's system image picker. Bundled Chinese ML Kit Text Recognition performs OCR on the device. The image is never uploaded by this application.
- OCR results are presented as original lines alongside Russian text obtained using the **existing** consented offline ML Kit translation model, built-in glossary and personal corrections. Copy is an explicit user action.
- The OCR screen works independently from the Pinduoduo Accessibility overlay enable switch. If the Chinese→Russian model is missing, OCR displays the original text and offers a link to the model settings; it does not silently download the translation model.
- **Personal glossary:** users can add, see and individually delete up to 200 local translation overrides. Overrides take priority over bundled dictionary and cached ML Kit translations; no new account or server is needed.
- Existing payment action, currency/amount, OTP and sensitive-label guards cannot be bypassed with user overrides.
- APK version `0.2.0-beta.4`, `versionCode 14`; package ID `app.pinduoduo.overlayru` and existing settings/license state remain unchanged.
- 8 new pure-policy tests in addition to the prior 39 release unit tests.

## Explicit limits and privacy
- OCR is a **manual image selection**, not continuous OCR in Pinduoduo. No screen recording, MediaProjection, file storage permission, Accessibility scope expansion, analytics or text upload is added.
- Chinese OCR model is bundled and works offline; Russian translations of previously unseen phrases require the downloaded ML Kit translation models obtained by prior user consent. Text recognition and offline translation are different subsystems.
- The image is decoded at a maximum 2048-pixel longest dimension before processing; at most 60 unique lines are displayed.
- Recognized monetary values and payment-confirmation buttons are left in the original language for purchase safety; always verify totals and checkout terms in the original Chinese.
- This stage does not implement an on-image overlay of translated graphics, capture full scrolling pages or translate product descriptions embedded in WebViews that OCR does not recognize.
- The personal glossary is stored in private SharedPreferences with app backup disabled. Uninstalling the app deletes these entries.
- **PRO remains optional** and does not unlock additional paid features. No payments or subscriptions are claimed.
