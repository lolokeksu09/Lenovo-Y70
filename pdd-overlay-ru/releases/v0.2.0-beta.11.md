# PDD Overlay RU v0.2.0-beta.11 — stabilization

## Goals
- Fix actual dictionary edit: rename or correct a saved phrase using one atomic preference commit, rejecting target-key collisions and missing original entries.
- Centralize four-tab top-level navigation through PddNav and FLAG_ACTIVITY_CLEAR_TOP | FLAG_ACTIVITY_SINGLE_TOP, including Home and Photo settings entry points.
- Publish a conventional readable Gradle/Android Studio source tree in pdd-overlay-ru/android/. The legacy beta10 source_bundle.base64 is a historical bootstrap source only.
- Add five JVM rename-policy regressions, retaining the existing 66.

## Release / validation boundary
- The workflow runs source/privacy tests, 71 JVM tests, a Gradle ARM64 build and native JNI/ABI checks.
- GitHub Actions intentionally produces an unsigned **internal** release build. It must NOT be distributed to a beta9/beta10 user as an update.
- A user-facing APK requires signing using the existing beta9/beta10 Kotlin signing key and verifying its SHA-256 certificate fingerprint d0d4e5dfb604917e1896c9a4697f2743296e3fa7b137d5bacefdf7a8c7b519d3.
- Device smoke: navigation/Back/OCR/keyboard, font scale 1.3, Accessibility toggles and offline model installation on Legion Y70 remain NOT RUN until actual device evidence exists.
- Avoid changing applicationId, local preferences, model download consent or protected-payment detection.
