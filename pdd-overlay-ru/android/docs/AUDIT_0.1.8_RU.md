# PDD Overlay RU — аудит v0.1.7 → v0.1.8

**База:** подписанная v0.1.7 (65 793 140 байт), исходный ZIP v0.1.7. Исходники сравнивались с ZIP побайтово. **Область:** только самостоятельное приложение; оригинальный Pinduoduo не менялся.

## Подтверждённые находки в v0.1.7

| Уровень | Компонент | Дефект / риск | Исправление v0.1.8 |
|---|---|---|---|
| Высокий | `PddAccessibilityService.render()` | `overlay.removeAllViews()` удалял все подписи при каждом событии, провоцируя мерцание, перераспределение макета и повторное создание View | `activeLabels` повторно использует надписи по `bounds::text`, удаляя только устаревшие |
| Высокий | `addLabel()` | Расширение до 60% ширины экрана без резервирования области правых кнопок могло перекрывать значения и стрелки | `OverlayPlacement.fit()` ограничивает положение исходной строкой и резервирует правую область, использует однострочное отображение |
| Средний | floating button | Неразделённые видимый размер и область касания, кнопка оставалась в произвольном месте при отпускании | Видимая 36dp окружность внутри окна 48dp, автоматическое закрепление у края, ограничения на системные области |
| Средний | Accessibility | Поверхность могла оставаться после незарегистрированного события смены окна | Периодическая проверка активного окна во время отображения кнопки |
| Средний | UI | Огромные технические блоки, основной запуск Pinduoduo расположен слишком низко | Компактный AMOLED-экран, первый экран с основной CTA, сворачиваемая диагностика, единая визуальная иерархия |
| Средний | ML Kit и VPN | Непонятно, что причиной зависшей загрузки может быть VPN (наблюдение на реальном телефоне) | Информационная проверка активного VPN; без подмены фактической диагностики CDN |

## Безопасность и совместимость

- Нет новых Android permissions; AccessibilityService по-прежнему фильтрует окно `com.xunmeng.pinduoduo`.
- Плашки по-прежнему `FLAG_NOT_TOUCHABLE`, кнопка — единственный элемент, перехватывающий касания.
- Права root, Shizuku, обход проверки подписи Pinduoduo не добавлены.
- `versionCode` 8 → 9, `versionName` 0.1.7 → 0.1.8; обновление возможно только при подписи прежним сертификатом.

## Проверки

- `bash scripts/test_local.sh`: проверка policy/manifest/dictionary, моделей, Accessibility ID, асинхронного обновления, координат и шести новых граничных сценариев `OverlayPlacement`.
- Android сборка: отдельно через GitHub Actions по зафиксированному SHA коммита.
- Сигнатура релиза: отдельно `apksigner verify --verbose --print-certs` и сверка SHA-256 сертификата с v0.1.7.
- **На телефоне НЕ ПРОВЕДЕНО:** реальное расположение на многострочных списках, сложные WebView, анимация окна, accessibility reconnect, offline-model e2e. Их нельзя объявить PASS по unit-тестам.
