# LenovoMotorolovichY70 — безопасная сборка v3.1-audit

Исправляем приложение Lenovo Y70 / Moto Edge 70 Max на основе исходников [f1rzen-n/LenovoMotorolovichY70](https://github.com/f1rzen-n/LenovoMotorolovichY70), фиксированный коммит `10ffc78b9c97326467dc457513d6182581416991`. Права и сведения об авторах upstream сохранены.

## Изменения v3.1
- **Debloater:** проверка реального состояния пакетов после команды, защита критических служб, отказ от неподтверждённой «заморозки» AppOps. Сохраняется журнал **только новых изменений**, выполненных приложением. Откат не включает посторонние отключения.
- **NFC:** предварительная проверка доступности маршрутов, повторное чтение после применения/отката, отказ от силовых повторов и автоматического удаления сторонних Magisk-модулей. Статус не гарантирует бесконтактную оплату.
- **Shell/Shizuku:** добавлен результат команды с кодом завершения; выдача WRITE_SECURE_SETTINGS подтверждается проверкой самого разрешения.
- **Сборка и тесты:** `tests/check_static.py`, `tests/check_v31.py`, `.github/workflows/build-audit.yml`. Версия `3.1-audit`, код `32`.

Исправления v3.0 сохранены: `pointer_speed` указан как скорость мыши/трекпада (не сенсора); игровой пресет не повышает якобы частоту опроса тача; неподтверждённый аппаратный Bypass Charging отключён. Независимое подтверждение работы DC Dimming и аппаратных функций отсутствует.

**Ограничения:** приложения, отключённые до установки v3.1, не входят в новый журнал — автоматический «полный откат к стоку» мог бы затронуть чужие изменения, поэтому удалён. Сборка CI подписана debug-ключом; перед переустановкой сохрани данные. Компиляция и статические тесты не заменяют проверку на реальном Lenovo Y70.

Подробности: [docs/v3.1-safety.md](docs/v3.1-safety.md).
