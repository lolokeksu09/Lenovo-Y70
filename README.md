# Lenovo Y70 Clone

Реконструированный Android-проект с интеграцией Shizuku, безопасными профилями дисплея и контролем ограниченного списка системных пакетов. **Не является оригинальным исходным кодом APK v2.6.**

## Текущая тестовая версия — v2.9

[**Скачать подписанный debug APK v2.9**](https://github.com/lolokeksu09/Lenovo-Y70/actions/runs/43062913010) → **Artifacts** → `LenovoY70-v2.9-Preview-APK` → `app-debug.apk`.

- Интерфейс разделов переработан по предоставленным скриншотам v2.6: именованные карточки, статусы, цветные действия, компактная типографика.
- Дисплей: QHD+/FHD+/HD+, 60/90/120/144 Гц и авто; перед изменениями снимок и 15-секундное подтверждение.
- Менеджер пакетов: 9 разрешённых пакетов, индивидуальные операции и групповые операции только после отдельного предупреждения и с попыткой отката. **Это не гарантия безопасности и полного восстановления**.
- Диагностика, локальные снимки, сравнение и экспорт JSON.
- ID debug-версии: `com.moto.resolution.clone.preview29`; устанавливается рядом с предыдущими версиями, не удаляя их.
- На Android CI: 29 тестов политики команд, UI-регрессии, сборка Gradle и проверка подписи через Android `apksigner`. На физическом Lenovo Y70 ещё не тестировалась.

## Исходный проект

CI восстанавливает исходники из `source/chunk-*.b64`, применяет базовое обновление из `overlays/v2.8/` и новые изменения из `overlays/v2.9/`, проверяя SHA-256 перед сборкой. Это текущий переносной формат источников; для удобной разработки в Android Studio следует перенести исходные файлы в нормальные каталоги репозитория.

Workflow: `.github/workflows/build-preview.yml`.
