# Lenovo Y70 — исправления v3.0-audit

Основная ветка создана заново на базе исходников [LenovoMotorolovichY70](https://github.com/f1rzen-n/LenovoMotorolovichY70) автора f1rzen-n (фиксированная ревизия `10ffc78b9c97326467dc457513d6182581416991`). Упоминания лицензии MIT, Shizuku и авторов NFC-фикса сохранены.

Исправлено: `pointer_speed` подписан как скорость мыши/трекпада, без ложных заявлений о настройке тача; пресет 144 Гц + 0.5x больше не изменяет указатель; частичный успех команд не объявляется полным. Фиктивный Bypass Charging отключён, Android-симуляция батареи и запись в `charging_enabled` больше не используются. Снята недоказанная гарантия NFC-оплаты на 100% терминалов и обещания 1500 Гц опроса сенсора.

В `overrides/` лежат исправленные Java-исходники, ресурсы и манифест, `tests/check_static.py` содержит статические проверки, а GitHub Actions собирает APK из зафиксированного upstream и патчей.

**Ограничения:** реальный телефон не подключён. Работа NFC, DC Dimming, Bypass, OLED, сетевых индикаторов, debloat и фактических режимов экрана НЕ подтверждена на устройстве. CI-APK подписывается новым debug-ключом, несовместимым с подписью уже установленного оригинального APK; не удаляйте старую версию без резервной копии данных. Полное стирание Git-истории и прежних Actions/релизов этим коммитом не выполняется.
