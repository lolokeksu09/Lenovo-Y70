# Lenovo Y70 — Android companion

Реконструированный проект Lenovo Y70 Clone v2.7 с Shizuku. Исходный код доступен в архиве `source/LenovoY70_v2.7_Source.zip` и в файлах текущего чата. GitHub Actions автоматически собирает отдельную тестовую версию `com.moto.resolution.clone.preview`.

**Важно:** это новая реализация, не оригинальные исходники APK v2.6; не заменяйте рабочую v2.6 до проверки на устройстве. Релизный ключ и пароли в репозиторий не загружаются.

Для получения APK откройте Actions → **Build Lenovo Y70 v2.7 Preview APK** → выберите последний успешный запуск → **Artifacts** → `LenovoY70-v2.7-Preview-APK`.
