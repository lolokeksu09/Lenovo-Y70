# Legion Control 1.7.0 — материалы для публикации на 4PDA

## Приложение
- **Название:** Legion Control (как в AndroidManifest.xml)
- **Версия:** 1.7.0; versionCode: 9
- **Имя пакета:** `dev.legion.control`
- **Минимальная версия Android:** 9.0 (API 28)
- **Разработчик / источник проекта:** GitHub `lolokeksu09/Lenovo-Y70`
- **Целевое устройство:** Lenovo Legion Y70 нового поколения, аппаратный SKU `XT2611-1`, с прошивкой Motorola Edge 70 Max
- **Доступ:** Shizuku, работающий через ADB Shell; root не требуется

## Описание
Legion Control — локальная утилита управления доступными настройками телефона через штатные интерфейсы Android и Shizuku. Приложение не меняет ядро, не прошивает разделы и не отключает критические пакеты.

## Функции
- Информация об устройстве, Android, SoC и ограничениях частоты дисплея; отдельно отображаются факты аппаратного SKU и название прошивки.
- Проверка установленных компонентов Motorola, доступных шрифтов Android и GameManager.
- Настройка частоты в разрешённых пределах, с проверкой режима 144 Гц на устройстве, и управление анимациями.
- Быстрые профили, предварительное сохранение исходных параметров и откат последнего изменения.
- Проверка и выборочная настройка фоновой работы отдельных приложений через AppOps.
- Локальный журнал последних 25 действий с экспортом TXT.

## Что изменилось в 1.7.0
- Экран «Данные устройства» стал структурированным: без UID, групп Linux и строк CLI в основном интерфейсе.
- Показания модели прошивки Motorola не выдаются за аппаратную модель телефона.
- Энергосбережение и значения min/peak частоты отображаются раздельно. Границы частоты не считаются фактическими FPS или текущей частотой экрана.
- Краткая сводка сохраняется в «Обзоре» без сырого shell-вывода.
- Добавлен блок «О приложении»: версия, Shizuku, совместимость и конфиденциальность.

## Установка
1. Установите Shizuku и запустите его через ADB (рутовый режим не нужен).
2. Установите единый подписанный Release APK Legion Control.
3. В Legion Control предоставьте разрешение Shizuku.
4. Для диагностики откройте «Обзор» и нажмите «Обновить данные устройства».

При обновлении с подписанных версий 1.1.0–1.6.0 пакет и сертификат остаются прежними; `versionCode` увеличен до 9. Установка поверх несвязанной debug/preview-подписи может быть невозможна: перед удалением старого приложения сохраните доступные данные. 

## Приватность и безопасность
- Приложение не запрашивает Android `INTERNET` permission.
- История действий хранится в локальных SharedPreferences; экспорт диагностических данных запускается только пользователем.
- Чтение параметров через Shizuku осуществляется локально. В отдельных диагностических TXT могут находиться имена системных пакетов и технические сведения.
- Изменение частоты, шрифтов и AppOps может повлиять на поведение системы и уведомления.
- Показания температур на чужой прошивке могут быть некорректными; приложение не меняет температурные лимиты.
- Откат предусмотрен для последней операции; журнал истории не предоставляет независимый откат любого старого события.

## Перед публикацией на 4PDA
- Прикрепить **готовый APK**, не ZIP со split-файлами, если приложение распространяется единым APK.
- Приложить настоящие полноразмерные скриншоты именно 1.7.0 с устройства: обзор, системные модули, дисплей, история.
- Проверить работу Shizuku, разрешений, экрана данных, переключения вкладок и отката на устройстве.
- Указать источник/автора и точную версию APK. Репозиторий GitHub может быть приватным: публичная ссылка на закрытую ветку не заменит доступный источник; при необходимости приложить ZIP исходников отдельно.
- Не заявлять поддержку других прошивок или устройств без практических тестов.
