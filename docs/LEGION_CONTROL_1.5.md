# Legion Control 1.5.0

## Улучшения интерфейса
- Заменён сырой вывод модулей Motorola, шрифтов Android, GameManager и дисплея на структурированные отчёты с описаниями и статусами.
- Технические сведения скрыты по умолчанию, их можно открыть и скопировать по запросу.
- Раздел «Система» переработан: плитки шрифтов, чтение активного шрифта, отдельные карточки AppOps со статусами «Разрешён», «Ограничен», «По умолчанию».
- Проверка отключённых пакетов показывает количество и отдельно предупреждает об отключённых компонентах экстренной связи.
- Сохранены AMOLED-палитра и верхние вкладки версии 1.4.1.

## Безопасность
- Никакие новые команды изменения системы не разрешены. Все операции чтения уже были в CommandPolicy.
- Вывод shell не исполняется как код, парсится отдельно и показывается как текст.
- Проверка ограничений AppOps не меняет существующие режимы.
- Сохраняются транзакционные снимки для отката настроек.
- Не вмешивается в ядро, thermal, загрузчик, root и критические приложения.
