# Alpha.2
Kotlin MVVM + Compose UDF: Activity owns lifecycle/navigation; screens render state and dispatch events. MainViewModel exposes read-only StateFlow, owns one operation, foreground polling and bounded sample history; AppCatalog and HistoryStore own data access. MemoryController coordinates Shizuku and Rust JNI. Rust owns mappings and returns opaque handles; per-block and total limits are checked at the native boundary. C++ and CMake are removed. AIDL keeps the existing limited am kill and dumpsys interface. Existing package and preference schema are preserved.
Verification: CI runs native Rust tests and Android unit tests, then assembles APK. Native tests exercise invalid lengths, wrong handles, double release, cleanup and cap. Device-level Shizuku, memory pressure and design verification still required.
