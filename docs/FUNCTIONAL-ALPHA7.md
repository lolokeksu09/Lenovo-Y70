# Alpha.7 acceptance
Adaptive native planning is opt-in. 40% available RAM skips native; missing PSI or thermal, PSI >=3%, thermal >=2, or available RAM <15% cap at SOFT; otherwise cap at BALANCED. Never increase requested profile; existing policy still blocks unsafe allocations. Explicit selected Shizuku commands remain unchanged. Auto cleanup retains existing SOFT settings. These are conservative heuristics, not empirically tuned device thresholds. In hybrid, recompute after shell stage. Journal stores actual native profile only when blocks allocated, planned bytes and reason; old history remains unknown. Strategy summaries exclude automatic, cancelled, failed and unmeasured records. No causal inference or automatic promotion based on historical median. Source tests cover guards, budget and actual route grouping. Full runtime and visual QA not performed.

Kernel memory counters are parsed with units and bounds, with independent optional values; missing readings remain unknown. PSI full is diagnostic only. Old JSON records retain null plan fields. No root or kernel tuning added.
