# Alpha.6 functional acceptance
- Applications: filter/search, request up to 20 visible eligible apps, keep partial samples on cancellation, rank known PSS ahead of unknown, show sample time and RSS; repeat batches for remaining apps. No automatic scanning or termination. Unknown is not zero. Package meminfo can include other Android profiles; ranking is not whole-device process inventory.
- Settings: opt-in manual comparison only, up to 12 selected eligible apps, before operation and after the settled system-memory measurement. No automatic comparisons. Preserve protection policy and existing cleanup behavior. Duration in journal measures cleanup, not all auxiliary diagnostics.
- Journal: show saved paired samples, missing values and deltas, preserve legacy entries, export a frozen snapshot of all records as UTF-8 CSV using Storage Access Framework. No broad storage permission; a process-death result cannot write a different snapshot.
- Source UI review: four tabs, selected semantics, scrolling filter rows, bounded scan progress, global cancel when switching tabs, comparison expansion and single-flight export. No new visual style dependencies. No emulator/ADB/Android SDK available in this execution environment; actual screen rendering, TalkBack, SAF document bytes on device, launcher widget, and real Shizuku scans remain NOT RUN.
- CI gates: domain tests including bounded sampling, cancel, paired measurement and CSV escaping; legacy codec round trip; presentation state tests; assembleDebug, Rust host tests and packaged JNI validation.
