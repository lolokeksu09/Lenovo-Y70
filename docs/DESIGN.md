# Design contract — alpha.2
AMOLED is retained. A muted blue denotes actionable controls, not arbitrary progress or success. Flat separated rows replace generic Card stacks; remove all-caps version kicker and glyph navigation. Home prioritizes the measured RAM and the real cleaning action. Graph uses live samples and fixed total-RAM scale; no fabricated measurements. App list uses actual labels and package identifiers, a compact selection row, filter and search. History reports observed changes, including negative values. No invented performance claims.
Static source audit found repeated Panel/Card wrappers, identical screen title treatment, decorative glyph tabs and duplicate headings. No emulator screenshots available yet: visual QA, font scaling and accessibility interaction remain NOT RUN.
