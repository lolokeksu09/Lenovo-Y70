# Review of alpha.2 (90bd271)
Verified prior CI and artifact. Source findings: (1) global releaseAll can release a different session if another owner is introduced; (2) controller declares completion even with no action, failed command or zero allocation; (3) immediate RAM delta is noisy and history counts skipped operations; (4) hold does not recheck protection; (5) no cooldown or stop on leaving screen; (6) unvalidated readings can pass policy. Alpha.3 addresses these in native ownership, injected controller, outcome model, measurement/legacy storage and UI. Preserve package, preferences and separate branch. Next separate review: Shizuku service timeout and permission lifecycle, process metrics, original APK automation/widgets (not yet implemented), visual/device review and benchmark. No runtime claims without device evidence.
